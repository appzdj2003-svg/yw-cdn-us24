# yw-cdn-us24

Your World Hunt AI — regional public-land CDN (manifests on `main` + GeoJSON on GitHub Releases).

CDN base: `https://raw.githubusercontent.com/appzdj2003-svg/yw-cdn-us24/main/{region}/manifest.json`

| Region | Manifest | Release asset | Source / license | Approx size |
|--------|----------|---------------|------------------|-------------|
| US | `us/manifest.json` | `land-us-v1` / `us-land.geojson` | PAD-US OA (USGS) CONUS | ~29 MB |
| CA | `ca/manifest.json` | `land-ca-v1` / `ca-land.geojson` | CPCAD 2025 terrestrial — Open Government Licence – Canada | ~22 MB |
| EU | `eu/manifest.json` | `land-eu-v1` / `eu-land.geojson` | EEA NatDA/CDDA 2025 — CC-BY 4.0 (largest sites) | ~35 MB |
| AU | `au/manifest.json` | `land-au-v1` / `au-land.geojson` | CAPAD 2024 terrestrial — CC-BY 4.0 | ~12 MB |
| WORLD | `world/manifest.json` | entitlement-only | Unlocks US+CA+EU+AU; download regions separately | — |

Guide only — not a survey. Verify access on the ground.

**Not included yet:** US AK+HI (follow-up `land-us-v2`), combined WORLD geojson.
